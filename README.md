# 🌾 Local Farmer Market Information System

A simple web-based application that provides local farmers and customers
with agricultural product and market price information.

## 🎯 Objective

The main objective of this project is to help farmers and customers
easily access information about agricultural products and local market prices.

## ✨ Features

- 🌾 Displays agricultural products
- 💰 Shows market prices
- 📍 Shows market locations
- 📱 Simple and responsive design
- 🌱 Easy-to-use interface
- 🌐 Hosted using GitHub Pages

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages
